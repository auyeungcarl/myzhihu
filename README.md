# 知乎交友检索与首次私信助手

本地运行的系统设计与浏览器适配原型。目标是扫描深圳择偶相关问题的近期回答，生成有来源依据的候选报告，并在已授权范围内只发送一次首次私信。

完整设计见：[系统设计方案](docs/系统设计方案.md)。文档包含架构图、模块边界、时间窗口、匹配规则、去重状态机、数据库模型、CLI 规格、异常恢复、测试验收和实施计划。

搜索与话术模板见：[检索关键词与执行提示词](docs/检索关键词与执行提示词.md)。`config.example.json` 提供 7 个默认关键词；本地 `config.json` 存放账号和个人资料，不进入版本库。多关键词编排执行仍待 Python 扫描器实现。

发送前须按 [goutoujunshi 首次私信生成规则](prompts/首次私信生成.md) 逐人生成并复核口吻，删掉套话，保留真实信息。配置已声明此要求，自动生成与发送门禁尚待实现；不能仅因存在配置就认为链路已接通。

## 当前状态

- 已有配置模板、Chrome AppleScript 桥接和 DOM 适配原型。
- 已验证 Chrome 独立标签页的只读访问，以及真实知乎回答和已有会话的页面结构。
- Python 编排器、SQLite 去重状态库、命令行入口及自动化测试尚未实现。
- 没有完成真实发送的端到端验收；不要直接调用 DOM 原型中的 `fill` / `submit` 进行生产发送。
- 设计文档中的命令属于待实现接口，不是当前可直接运行的脚本。

## 环境与原则

目标环境为 macOS、Google Chrome、Python 3.11+。Chrome 需已登录本人知乎账号，并开启 `View → Developer → Allow JavaScript from Apple Events`。

首次使用时执行 `cp config.example.json config.json`，再填写本人主页、真实资料、排除名单和本机技能路径。`config.json` 已被 Git 忽略；不要在模板中填写真实账号资料。

复用浏览器会话，不保存密码。已有历史会话、已知联系记录或发送结果未知时跳过，不自动重发。扫描默认只读，实际发送须通过身份、匹配、授权、去重与额度检查。

额度上限为每个北京时间自然日最多 5 次首次招呼（`config.json` 的 `max_sends_per_day`），跨多次运行共享；每人仅 1 条，额度不足即停止并报告剩余数。

不要把密码、登录 Cookie 或会话令牌加入任何配置文件。
