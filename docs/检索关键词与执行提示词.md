# 检索关键词与执行提示词

更新时间：2026-10-04。本文提供默认搜索词、可选扩展和可复用任务提示词。关键词用于发现问题，不表示已经核实对应问题存在或其中有最近一天的合适回答。

## 1. 已加入默认配置的搜索词

`config.json` 的 `search_queries` 共 7 项：

| 搜索词 | 来源 |
| --- | --- |
| 深圳的你 择偶 | 原有入口 |
| 深圳择偶标准是什么 | 用户补充 |
| 深圳的你 择偶标准是怎样的 | 用户补充 |
| 深圳的湖南人择偶标准 | 用户补充，优先检查共同地域经历 |
| 深圳的你择偶标准 | 用户补充 |
| 深圳找对象 | 用户补充 |
| 深圳交友贴 | 用户补充 |

相近搜索词先保留，不能假定平台会返回完全相同的结果。搜索后按问题 ID 合并，保留来源词；作者跨问题出现时再次去重。加入配置不等于当前原型已经能自动执行完整扫描。

## 2. 推荐的可选扩展

以下暂未加入默认配置，可根据实际召回量逐步启用。优先增加不同人群或兴趣线索，减少无意义的同义改写。

| 优先级 | 搜索词 | 用途与筛选提醒 |
| --- | --- | --- |
| 高 | 湖南人在深圳 找对象 | 与湖南背景直接相关，核实当前工作城市 |
| 高 | 深圳 湘潭 征友 | 可能找到同乡，结果数量可能较少 |
| 高 | 深圳 福田 征友 | 与工作地点接近，仍需看实际居住及活动范围 |
| 高 | 深圳 女生 征婚 | 更明确的关系意愿，但注意代征和商业内容 |
| 高 | 深圳 硕士 找对象 | 寻找相似求学经历，不把学历当唯一标准 |
| 中 | 深圳 徒步 找对象 | 用共同兴趣发现候选；单纯徒步活动不代表征友 |
| 中 | 深圳 羽毛球 征友 | 注意区分球友邀约与择偶意愿 |
| 中 | 深圳 乒乓球 找对象 | 补充另一项真实兴趣 |
| 中 | 深圳 喜欢做饭 征友 | 便于找到自然、具体的聊天切入点 |
| 中 | 深圳 程序员 择偶 | 同行业或相关经历；仍需筛选成年女性自述 |
| 扩展 | 湖南的你 择偶的标准是怎样的 | 已知存在这类话题，但需筛出目前在深圳的回答；发现层需支持标题无“深圳”的问题 |
| 扩展 | 在深圳 如何找到对象 | 可能更多是方法讨论；仅在本人回答明确征友时进入候选 |

检索词中的“女生”“征婚”只是召回线索，不是对账号身份或关系意愿的确认。不得因为出现在兴趣话题下就自动发送恋爱招呼。

## 3. 一次完整任务提示词

下面的提示词适用于具备浏览器操作能力的执行器。它描述目标行为，不表示当前 Python 脚本已实现。

```text
请执行一次知乎交友检索，按既定授权策略联系符合条件且从未联系过的对象。

我的资料：1992年出生，湖南湘潭人，目前在深圳生活，在福田金融公司做开发；2018年某985大学研究生毕业；身高约170cm，体重约62kg，长沙已购房。爱好徒步、乒乓球、羽毛球和下厨，喜欢科技、地理、历史、投资相关书籍与视频。遇到合适的人，可以考虑一年内结婚。不要补充未提供的收入、婚史、烟酒习惯或定居安排。

登录：复用Chrome中已登录的本人知乎会话，核实账号对应 https://www.zhihu.com/people/carl-1/answers 。需要登录或验证码时提示我完成，不保存密码。

检索：逐个执行config.json中的search_queries，并扫描question_urls中的固定问题。可选扩展词只有在本轮明确启用时才执行。记录每个词的成功、失败或未完成状态。

时间：以本次开始时间固定最近24小时窗口，按北京时间展示。进入问题后核实“按时间排序”。用首次发布时间筛选；今天编辑的旧回答单独记录，不计入今天的新回答。

筛选：只依据完整公开原文，寻找明确成年、女性、本人当前有交友或择偶意愿、在深圳生活工作或明确愿意在深圳发展关系的人。至少有一个真实共同兴趣或经历。核对对方硬条件；有冲突则跳过，重要事实未知则待确认，不默认满足。

去重：合并不同搜索词发现的相同问题；同一作者跨问题去重。发送前检查本地记录和准确的知乎会话。已经联系过、存在任何会话消息、已有草稿、发送结果未知或无法确认历史的对象都不发送。昵称只作线索，不能独立证明身份。

招呼：发送前必须实际读取并应用goutoujunshi技能及其“实战话术编排器”参考，按prompts/首次私信生成.md逐人生成，再复核口吻。使用短句、真实细节和适量自我介绍，最多一个自然的问题，不为凑字数扩写。删掉报告式开头、空泛赞美和套话，不强行加“哈哈”，不编造经历。对方要求自我介绍时，不只发“你好”“认识一下”。技能不可用或复核未通过时，不使用通用模板自动发送。

执行：按已有联系策略执行，每人最多一条，每个北京时间自然日累计最多5 条（先核对当日剩余额度，不足即停止并报告）；先持久化发送意图，再点击一次。发送后重新读取会话确认；结果不明则锁定且不重试。不自动续聊，不开启定时任务。

输出：列出时间窗口、实际搜索词、扫描问题、覆盖限制、候选来源与判断依据，以及跳过、待确认、已确认发送或发送未知等状态。访问失败不能描述成“没有合适对象”。
```

## 4. 单条回答筛选提示词

```text
请依据下方用户资料与知乎回答，判断是否适合首次联系。仅把原文明确写出的信息当事实，不从头像、昵称或语气猜测。

用户资料：<真实资料>
回答正文：<完整原文>
来源：<回答链接、作者主页、首次发布时间、编辑时间>
已有联系状态：<已联系／可证未联系／未知>

请输出：
1. 时间窗口是否符合，首次发布与编辑分别何时。
2. 是否为本人征友，是否能确认成年女性，以及深圳生活工作的依据。
3. 共同兴趣或经历：引用原文。
4. 对方硬条件逐项对照：通过／不通过／未知，并说明依据。
5. 已有联系或去重状态。
6. 结论：可进入联系计划／需要补充信息／跳过。

任何关键未知不得输出“完全符合”。本次只做分析，不发送消息。
```

## 5. 个性化招呼生成提示词

```text
请先读取并应用goutoujunshi/SKILL.md及“实战话术编排器：从一句回复到后续分支.md”，按本项目prompts/首次私信生成.md的规则，根据已核实的共同点，为这位公开征友的女生写一条自然的首次私信。

我的真实资料：<资料>
她的相关原话：<一至三句原文>
已确认的共同点：<具体兴趣或经历>
她对私信的要求：<例如请带自我介绍>

只给一个版本，通常2–4句。自然回应一个原文细节，再介绍相关的自身信息，最多一个轻量问题，不强行问问题或凑字数。按用户偏短、直接的口吻写，不用泛泛赞美、排比、报告式开头和统一群发模板。保持“身高约170”等真实限定，不假装完全满足未知条件，不承诺结婚时间或定居城市，不索要联系方式。生成后先按技能复核口吻和事实，再给出最终正文；不把分析混进消息。

如果没有可核实的共同点，或已知此前联系过，说明原因，不生成新的首次招呼。本次只生成文案，不能据此声称已经发送。
```

条件示例：只有对方确实写过喜欢徒步时，才可以参考下面这句；发送前仍须完成时间、匹配、身份和去重核验。

> 看到你也喜欢徒步，想来认识下。我92年，湘潭人，在福田做开发，平时也打羽毛球。你最近有走过什么不错的路线吗？

发送前的完整技能加载、口吻复核及内部输出要求见[首次私信生成](../prompts/首次私信生成.md)。这只是口吻示例，不能发给没有对应兴趣的对象，也不能用来补发给此前已联系的人。

## 6. 还值得补齐的本人资料

这些是影响自动匹配的资料项，不是本次新增搜索词的前置条件；尚未确认的继续保持未知：

- 年收入是否愿意提供一个区间，是否接受对方有收入门槛。
- 是否计划长期留深圳，长沙房产与未来居住安排的关系。
- 抽烟、饮酒、出差频率等生活和工作习惯。
- 生育预期、婚后是否与父母同住。
- 对方年龄和活动距离是否有明确偏好；未提出时不擅自设门槛。
